# One package for QGIS 3 (Qt5) and QGIS 4 (Qt6): every Qt import goes through
# qgis.PyQt with scoped enums, and the suite is green on 4.2.0.
#
# The cap is 3.99 all the same. infrared-sdk-installer 1.0.0 does not work on
# QGIS 4.x on Windows, so a user there installs the plugin and then cannot get
# its dependencies; and on QGIS 4 macOS the bundle's own pyarrow (built without
# `dataset`) wins over ours, so ground-material downloads fail outright. The
# Plugin Manager trusts this line before loading any code, so it is a PROMISE,
# not a capability check, and the plugin cannot walk it back from the inside.
#
# Do not raise it because the Qt6 code is ready — that is what makes this look
# like a typo. Raise it when the installer works on QGIS 4.x Windows AND the
# docs/manual-testing.md round has passed there. See CLAUDE.md, Stack.
qgisMaximumVersion=3.99
description=Run urban climate simulations (wind, thermal comfort, solar) directly from QGIS using the infrared.city platform.
version=1.2.0
author=infrared.city
email=connectors@infrared.city

about=Infrared City GIS is a QGIS plugin that connects to the infrared.city simulation platform. It allows urban planners and climate consultants to download building geometry with the help of Infrared City platform, run microclimate analyses (wind speed, pedestrian wind comfort, thermal comfort index, solar radiation, daylight availability, direct sun hours, sky view factors), and visualize results as raster layers directly in QGIS. External dependencies: the plugin installs infrared-sdk, numpy, pyarrow, shapely, mapbox_earcut and structlog into your QGIS profile on first start, so the first launch needs an internet connection; a paid infrared.city subscription and API key are required to run simulations.

tracker=https://github.com/Infrared-city/qgis-plugin/issues
repository=https://github.com/Infrared-city/qgis-plugin

    - Important: this release moves the plugin off a server the platform is retiring. Earlier versions will stop being able to download ground materials, weather data and material registries once that happens — please update.
    - Ground materials now cover the edges of your simulation. The download reaches about 800 m beyond your selection, because every simulation tile reads surfaces well outside itself; without that band the edge of a result was computed as if the ground materials were not there. The ground-* layers you get back are correspondingly larger than the area you picked, and the download takes longer.
